# BOTB Judges Edition

ئەمە ئەپێکی سەربەخۆی Judges Edition ـە، نەک ئەپی ڕەسەنی BOTB. Signing لێرەدا ناکرێت. خۆت signing دەکەیت.

IPAـی نەواژۆکراو لێرە دەردەچێت:

1. Actions
2. Build BOTB Judges Edition unsigned IPA
3. Artifacts
4. BOTB_Judges_Edition_unsigned_ipa

کۆدی بەکارهێنراو لە ڕیشەی ڕێپۆکەیە. فایلە دووبارەکان کە ناویان ` 2` یان ` 3`ـە بەکارمەهێنە. پارچەکانی `BotbIPA.part-*` تەنها ئەرشیفی IPAـی کۆنن و نابنە بە ئەپی نوێ.
